# 개념 블록 실습장 (concept-sandbox)

B1-1 미션 착수 전 개념 블록 A·B·C의 **연습용 예제**를 모아둔 곳이다.

## 이 폴더의 성격

| 항목 | 내용 |
|---|---|
| 목적 | 개념을 손으로 확인하는 것. **미션 산출물이 아니다** |
| 산출물 | 코드가 아니라 `knowledge/glossary.md`의 🟡 항목 |
| 처분 | 블록이 끝나면 지워도 된다. 학습 이력으로 남겨도 무방 |
| 제출 | **제출 대상 아님.** 미션 제출물은 `b1-1-portfolio/` 뿐이다 |

## 왜 미션 폴더와 분리했는가

과제 요구사항 F-01이 미션 폴더 구조를 `index.html` / `css/` / `js/` / `images/`로
지정하고 있다. 연습 파일을 그 안에 두면 채점자가 볼 폴더 구조가 지저분해진다.

## 구조

```
concept-sandbox/
├── a-css/    개념 블록 A -- CSS 레이아웃
├── b-js/     개념 블록 B -- JavaScript 기초 (예정)
└── c-async/  개념 블록 C -- 비동기·네트워크 (예정)
```

## 실습장 규칙

미션 폴더의 금지 사항 일부는 여기서 **완화된다.** 이유는 아래와 같다.

| 항목 | 미션 폴더 | 실습장 | 이유 |
|---|---|---|---|
| `<style>` 블록 | 금지 (외부 CSS 필수) | **허용** | 파일 하나로 끝내야 관찰이 빠르다 |
| `style="..."` 속성 | 금지 | **금지 유지** | 나쁜 습관이 되므로 예외를 두지 않는다 |
| `var` | 금지 | **금지 유지** | 같은 이유 |

> `<style>` 블록과 `style="..."` 속성은 다른 것이다.
> 전자는 CSS를 모아 쓰는 자리이고, 후자는 요소 하나에 직접 박아넣는 것이다.
> 과제가 금지하는 것은 **후자**다.
