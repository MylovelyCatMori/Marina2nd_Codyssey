A3 실습 · 박스 모델

F12 → Elements 탭에서 요소를 클릭하고, 오른쪽 아래 Computed 패널의 박스 그림을 함께 보십시오. 색깔별로 margin / border / padding / content 가 표시됩니다.

실험 1 · width: 300px 는 무엇의 300px 인가

↑ 이 빨간 점선이 폭 300px 기준자입니다

box-sizing: content-box (브라우저 기본값)

width 300 + padding 20×2 + border 10×2

box-sizing: border-box

width 300 안에 padding 과 border 가 포함된다

실험 2 · 위아래 margin 은 더해지는가

첫 번째 (margin-bottom: 40px)
두 번째 (margin-top: 40px)

실험 3 · padding 과 margin 의 차이

기준 (여백 없음)
padding: 30px
margin-left: 30px
