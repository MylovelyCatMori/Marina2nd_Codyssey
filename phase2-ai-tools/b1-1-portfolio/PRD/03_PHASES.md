## 개념 블록이 왜 들어갔는가 (2026-09-09 추가)

훑기 결과 A그룹 38개 **전량이 실질 신규**로 확인되었다. 특히 `const` / `let` / `var`가 신규라는 것은 자바스크립트 변수 선언부터 처음이라는 뜻이다.

이 상태에서 "구현하면서 배운다"를 하면 결과가 이렇게 된다.

```
코드는 돌아간다  →  왜 돌아가는지 모른다  →  동료평가에서 설명 못 한다
                                          →  규정상 부정행위로 간주될 수 있다 (OT p.17)
```

따라서 Phase 1·2·3 **앞에** 개념 블록 A·B·C를 배치한다. 각 블록은 공통 `LEARNING_RULES.md`의 **개념 → 어원 → 비유 → 실습** 순서를 따르며, 미션 코드가 아니라 **버리는 예제**로 진행한다.

> **핵심 원칙**: 개념 블록의 산출물은 코드가 아니라 **`glossary.md`의 🟡 항목**이다.
> 예제 파일은 블록이 끝나면 지워도 된다. 남는 것은 설명할 수 있는 상태다.

**블록 공통 진행 방식**

| 단계 | 하는 일 |
|---|---|
| 1. 개념 | 이게 무엇을 해결하려고 생긴 것인가 |
| 2. 어원 | 왜 이 이름이 붙었는가 (개발 용어 대부분은 영어 단어 그대로다) |
| 3. 비유 | 일상의 무엇과 닮았는가 |
| 4. **예측** | 실행하면 어떻게 될지 **먼저 말한다** (공통 규칙) |
| 5. 실습 | 10~20줄 예제를 직접 타이핑해 실행하고 예측과 대조한다 |
| 6. 기록 | `glossary.md`에 5칸을 채워 🔴 → 🟡 승급 |

> **4번이 핵심이다.** 예측이 틀렸을 때 가장 많이 배운다. 맞히는 것이 목적이 아니다.
