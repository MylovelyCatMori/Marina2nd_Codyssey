## 2. 왜 `readlines()` 대신 `yield` 인가

- **무엇**:
- **왜**:
- **안 그랬으면**:

<details>
<summary>채점 힌트</summary>

- 여기는 **성능(정확히는 메모리)이 진짜 이유**인 유일한 항목이다.
- `readlines()` / `list(reader)` 는 파일 전체를 메모리에 올린다. 10만 건이면 10만 건이 다 올라간다.
- `yield` 는 한 건씩 꺼내므로 **파일 크기와 무관하게 메모리가 일정**하다.
- 한 단계 더: **정렬은 스트리밍으로 못 한다.** 전체 순서를 알아야 하므로, 정렬은 걸러낸 결과에만 적용한다.
</details>

## 3. 왜 수정·삭제를 임시 파일 + `os.replace` 로 하는가

- **무엇**:
- **왜**:
- **안 그랬으면**:

<details>
<summary>채점 힌트</summary>

- 원본에 직접 쓰다가 프로그램이 죽으면 **파일이 반쪽으로 남는다.**
- 임시 파일에 전부 쓴 뒤 이름을 바꾸면 교체는 **성공하거나 실패하거나 둘 중 하나**이고 중간 상태가 없다.
- 한 단계 더: 임시 파일을 **같은 폴더**에 두는 이유는, 다른 디스크로 옮기면 교체가 원자적이지 않기 때문이다.
- **오답 주의**: "더 빠르다"가 아니다. 오히려 전체를 다시 쓰므로 느리다. 안전성과 맞바꾼 것이다.
</details>

## 4. 왜 예산이 없는 달은 "예산 0원"으로 표시하지 않는가

- **무엇**:
- **왜**:
- **안 그랬으면**:

<details>
<summary>채점 힌트</summary>

- 사용률 = 지출 ÷ 예산 이다. 예산이 0이면 **0으로 나누기**가 된다.
- "없음"과 "0원"은 다른 상태다. 0원은 "예산을 0으로 정했다"는 뜻이 된다.
- 코드에서는 `get()` 의 반환 타입이 `Budget | None` 이라 호출부가 "없을 수도 있다"를 반드시 처리하게 된다.
- 그래서 **예산 줄 자체를 출력하지 않는다.**
</details>

- **무엇**:
- **왜**:
- **안 그랬으면**:

<details>
<summary>채점 힌트</summary>

- 저장소는 값을 돌려줄 뿐이고, **화면에 무엇을 보여줄지는 CLI가 정한다.**
- 예: `ensure_files()` 는 새로 만든 파일 이름 목록만 돌려주고, "기본 카테고리를 등록했습니다" 안내는 `cli.py` 가 출력한다.
- 안 지키면 저장 형식을 JSONL/SQLite로 바꿀 때 출력 문구까지 딸려 나오고, 테스트에서 화면 출력을 막을 수 없다.
- 한 단계 더: CSV에는 외래키 제약이 없어 "사용 중 카테고리" 같은 정합성은 **서비스 계층**이 지킨다.
</details>

## 보너스: 코드 읽는 눈 (규칙 2)

아래 3개는 "지우면 어떻게 되나"로 답합니다. 막히면 **실제로 지우고 실행**해 보십시오.

| 코드 | 지우면? |
|---|---|
| `@functools.wraps(func)` (`decorators.py`) | |
| `field(default_factory=list)` → `= []` (`models.py`) | |
| `sys.stdin.reconfigure(encoding="utf-8")` (`__main__.py`) | |

<details>
<summary>채점 힌트</summary>

- `wraps` 없으면 모든 함수 이름이 `wrapper` 가 되어 로그에서 어느 명령인지 알 수 없다.
- `= []` 로 쓰면 **모든 거래가 태그 리스트 하나를 공유**한다. 한 건에 태그를 넣으면 다른 건에도 붙는다.
- `stdin` 인코딩을 안 맞추면 Windows에서 한글 메모가 깨진 채 들어와 저장 단계에서 `UnicodeEncodeError` 가 난다.
  **이 셋은 실제로 이번 구현 중에 터진 문제다.**
</details>
