### 명령 10종

```
add      거래 추가 (대화형)
list     최신순 목록 (--limit)
search   조건 검색 (--from --to --category --type --q --tag)
summary  월별 요약 + 예산 경고 (--month --top)
budget   월 예산 설정 (set --month --amount)
category 카테고리 관리 (add / list / remove)
update   거래 수정 (--id, 대화형)
delete   거래 삭제 (--id)
import   CSV 일괄 등록 (--from)
export   조건부 CSV 저장 (--out + 기간 필수)
```
