## 3. 기능 요구사항

### 3-1. 실행 및 입력 방식

| ID | 요구사항 | 상태 |
|---|---|---|
| F-01 | `python -m budget_app <command> [options]` 형태로 실행 | ✅ |
| F-02 | **모든 명령**에 `--help` 옵션으로 사용법 출력 | ✅ |
| F-03 | 입력 기본 방식은 **대화형** (`add`는 `input()` 순차 입력) | ✅ |
