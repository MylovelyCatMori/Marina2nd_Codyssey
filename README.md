# Codyssey with Claude - 프로젝트 개요

## 1. 이 프로젝트란?

이 저장소는 **Codyssey AI 올인원 제2기** 과정을 이수하면서 수행하는 모든 미션, 학습 기록, 지식 정리를 담는 공간이다.

단순히 과제를 제출하는 것이 아니라, 각 미션을 통해 얻은 지식을 내면화하고, 이후 현장에서 직접 활용 가능한 역량으로 쌓아가는 것이 목적이다.

## 5. 나의 학습 배경 및 목표

### 현재 상황

- 대한민국 제약사 생산 사업장 근무
- 개발/AI 비전공자
- Physical AI 시대를 현장에서 직접 목격하게 될 위치

### 목표

**현장(제약 생산)과 기술(AI/SW)을 잇는 중간자 역할로 독보적인 위치 확보**

구체적으로:
1. 개발 기초 역량 체득 (CS, Python, Linux, Docker, Git)
2. AI 기술 이해 (LLM, CV, NLP, ML/DL)
3. Physical AI 시대 제약 생산 현장 적용 가능성 탐색
4. 도메인 특화 AI 서비스 설계/구현 역량

### 이 교육이 나에게 의미하는 것

하용호의 "운영의 책임자" 개념처럼, 단순히 AI 도구를 사용하는 사람이 아니라 **현장 문제를 정의하고, AI로 해결하며, 그 결과에 책임지는 사람**이 되는 것이 목표다.

## 6. 학습 도구 활용 전략

### Claude와 함께하는 학습 구조

이 프로젝트에서 Claude는 단순한 코드 작성 도우미가 아니다. 다음 역할을 담당한다:

```
1. 미션 가이드      - 각 미션의 목적과 핵심 개념 설명
2. 개념 설명       - "왜?"를 포함한 상세 설명
3. 지식 검증       - grill-me로 이해도 확인
4. 전문가 시각      - AI-tutor 스킬로 현장 연결 관점 제공
5. 지식 누적       - 미션별 학습 내용 정리 및 기록
```

### 활용 스킬 목록

| 스킬 | 목적 | 사용 시점 |
|------|------|------|
| `grill-me` | 현재 세션 내 이해도 검증 (세션 종료시 휘발) | 개념 학습 직후 즉각 검증 |
| `grill-with-docs` | grill 산출물을 MD로 저장 -> 다음 세션 재활용 (지속성) | 미션 완료 전, 다음 세션에 넘길 지식 고착화 |
| `show-me-the-prd` | PRD 4종 + 요구사항 추적표 생성 | 미션 설계 단계 |
| `kkirikkiri` | 코드/요구사항/문서 교차 검증 | 동료평가 신청 직전 |
| `AI-tutor` | 현장(제약/Physical AI) 연결 관점 질문 | 개념 학습 후 현장 적용 탐색 |
| `deep-research` | 특정 기술 심층 배경 이해 | 단발 궁금증이 아닌 체계적 조사 필요 시 |

### 학습 사이클 (매 미션, 본과정 개정판)

용어와 설명 역량을 사이클 안에 못 박았다. 근거: 본과정 합격 기준 = "원리를 설명할 수 있는가".
상세 규칙은 `LEARNING_RULES.md` **기초 역량 보완 루프**.

```
미션 수령
    -> [용어 수집] 과제·강의자료 훑고 모르는 단어만 glossary.md에 🔴 (15분)
    -> Claude와 개념 학습 (왜? 포함, 새 용어는 그 자리에서 한 줄 정의)
    -> 직접 실습 수행
    -> [코드 읽기] 핵심 20~30줄을 "동작 / 의도 / 지우면 어떻게 되나" 3단으로 번역
    -> grill-me로 이해 검증
    -> [용어 채우기] 🔴 전부를 5칸 채워 🟡로 승급
    -> kkirikkiri 코드·요구사항 검증
    -> [3문장 리허설] 핵심 설계 결정 3~5개를 "무엇/왜/안 그랬으면" 으로 말하기
    -> 동료 평가 신청  (설명 통과한 용어는 🟢)
    -> AI-tutor에게 Smart Factory 연결 관점 질문 -> 한 줄 기록
```

> 주 1회 5분: `glossary.md`의 🟡 5개를 화면 덮고 설명. 막히면 🔴로 강등.
> 넣는 것보다 **꺼내는 연습**에서 굳는다.

## 10. 핵심 원칙

> **"단순히 Claude의 가이드를 따라하는 것이 아니라, 내가 직접 수행하고 설명할 수 있는 수준으로 체득한다."**

- 모든 명령어는 직접 입력하고 출력을 직접 읽는다
- 이해가 안 되면 grill-me로 검증한다
- 현장 연결 관점은 AI-tutor에게 질문한다
- 기록은 항상 남긴다
