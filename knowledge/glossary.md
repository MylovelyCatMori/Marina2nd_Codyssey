# 용어 사전 (Glossary)

> **목적**: 동료와 같은 언어로 말하기 위한 단일 사전. 코드를 읽을 때 "이 단어를 모르겠다"가 나오면 여기에 쌓는다.
> **원칙**: 한 줄 정의는 **내 말로** 쓴다. 남의 문장을 붙여넣으면 설명할 때 다시 막힌다.
> **관련**: 개념 단위의 긴 설명은 `general-concepts.md` / `phase1-concepts.md`. 여기는 **단어 단위**.

---

## 사용법

**① 수집 (학습 중)**
모르는 단어를 만나면 즉시 `상태 = 🔴` 로 이름만 적는다. 정의는 나중에. 흐름을 끊지 않는 게 더 중요하다.

**② 채우기 (미션 종료 전)**
🔴 항목을 표 형식으로 채운다. 5칸 전부 채워야 한다.

| 칸 | 왜 필요한가 |
|---|---|
| 한 줄 정의 | 동료평가에서 첫 문장으로 나가는 말 |
| 어원 / 왜 이 이름 | 이름을 알면 안 잊는다. 개발 용어 대부분은 영어 단어 그대로다 |
| 비유 | 상대가 못 알아들었을 때 꺼내는 두 번째 카드 |
| 내가 본 곳 | 파일:줄 또는 미션명. **추상적 암기를 막는 장치** |
| 헷갈리는 짝 | 비슷해서 섞이는 단어. 구분해서 말할 수 있어야 안다고 할 수 있다 |

**③ 상태 표기**

| 표기 | 뜻 |
|---|---|
| 🔴 | 이름만 안다 |
| 🟡 | 정의는 쓸 수 있으나 남에게 설명해본 적 없다 |
| 🟢 | 소리 내어 설명해봤고 막히지 않았다 |

> 🟢 판정 기준: **책/화면을 안 보고 30초 안에 정의 + 비유 + 실제 사례를 말할 수 있는가.**
> 이 기준을 통과한 것만 🟢. 스스로에게 후하면 동료평가에서 그대로 드러난다.

## Phase 1 (입학연수) 확보 용어

| 상태 | 용어 | 한 줄 정의 | 어원 / 왜 이 이름 | 비유 | 내가 본 곳 | 헷갈리는 짝 |
|---|---|---|---|---|---|---|
| 🟢 | 이미지 (Image) | 컨테이너를 만들어내는 읽기 전용 원본 | 원본을 그대로 찍어낸다는 뜻의 image(상, 사본) | 붕어빵 틀 | M1 `docker images` | 컨테이너 |
| 🟢 | 컨테이너 (Container) | 이미지를 실행해 만든, 격리된 프로세스 | 화물 컨테이너 - 안에 뭐가 들었든 규격이 같다 | 틀로 찍어낸 붕어빵 한 개 | M1 `docker ps -a` | 이미지 / 가상머신 |
| 🟢 | 볼륨 (Volume) | 컨테이너가 지워져도 남는 데이터 저장 공간 | volume = 담기는 부피 | 짐은 창고에 두고 방만 바꾸기 | M1 볼륨 영속성 검증 | 바인드 마운트 |
| 🟢 | 바인드 마운트 | 호스트의 특정 폴더를 컨테이너 안에 그대로 연결 | bind(묶다) + mount(끼워넣다) | 내 책상 서랍을 옆방에서도 열게 통로를 뚫음 | M1 반영 확인 실습 | 볼륨 |
| 🟢 | 포트 매핑 | 호스트의 포트 요청을 컨테이너 포트로 넘겨주는 연결 | port = 항구, 배가 드나드는 입구 | 건물 대표번호 → 내선번호 연결 | M1 `-p 8080:80` | 포트 번호 대역 |
| 🟢 | 커밋 (Commit) | 변경 내용을 하나의 기록 단위로 저장소에 확정하는 것 | commit = 확정하다, 맡기다 | 원고를 한 페이지 단위로 봉인 | M2/M3 전 STEP | 스테이징(add) |
| 🟢 | Fast-forward 병합 | 갈래가 갈리지 않아 브랜치 포인터만 앞으로 옮기는 병합 | 되감기 없이 앞으로만 감김 | 한 줄로 선 사람들, 앞 사람 자리로 이동 | M2 `feature/play` 병합 | 3-way merge |
| 🟢 | MAC 연산 | 곱하고 더하기를 한 번에 처리하는 계산 단위 | Multiply-ACcumulate 약자 | 장바구니: (단가×수량)을 계속 합산 | M3 `mac()` | 행렬곱 |
| 🟡 | 부동소수점 오차 | 10진 소수를 2진수로 정확히 못 담아 생기는 미세한 차이 | floating point - 소수점이 떠다님 | 1/3을 0.333…으로 적을 때 어디서 끊든 손해 | M3 epsilon 비교 | 반올림 오차 |
| 🟡 | O(N²) | 입력이 N배 늘면 시간이 N²배로 느는 성질 | Order of - 증가 차수 | 참석자 전원이 서로 악수 | M3 성능 분석 | O(N log N) |
| 🟡 | 상속 (Inheritance) | 자식 클래스가 부모 클래스의 성질을 물려받는 관계 | 유산 상속과 같은 단어 | `UnicodeDecodeError`는 `ValueError`의 자식 | M3 예외 3종 함정 | 포함(composition) |
