## Week1 Mission1: 개발 워크스페이스 구축

### 핵심 개념

#### 절대경로 vs 상대경로
- **절대경로**: 루트(/)부터 시작. 어디서든 동일한 위치를 가리킴. 예) `/home/user/docs/file.txt`
- **상대경로**: 현재 위치 기준. 예) `./docs/file.txt`, `../other/`
- **왜 중요한가**: Dockerfile, 스크립트에서 경로 오류의 90%가 이 차이에서 발생

#### 파일 권한 (r/w/x)
- `r=4`: 읽기, `w=2`: 쓰기, `x=1`: 실행
- `755 = rwxr-xr-x`: 소유자 모든권한 / 그룹+others 읽기+실행
- `644 = rw-r--r--`: 소유자 읽기+쓰기 / 그룹+others 읽기만
- **왜 중요한가**: 실행 파일에 x 없으면 Permission denied 오류

#### Docker 핵심 개념
- **이미지**: 실행 환경의 스냅샷. 불변(immutable).
- **컨테이너**: 이미지로부터 실행된 인스턴스. 격리된 프로세스.
- **포트 매핑 `-p 8080:80`**: 호스트 8080 → 컨테이너 80. 컨테이너 격리 때문에 필요.
- **볼륨**: 컨테이너 생명주기와 독립적인 영속 저장소.

#### Git vs GitHub
- **Git**: 로컬 버전관리 도구. 변경 이력 추적.
- **GitHub**: 원격 협업 플랫폼. Git 저장소 호스팅 + 코드리뷰 + 이슈관리.
