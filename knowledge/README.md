## 구조

| 파일 | 내용 |
|------|------|
| phase1-concepts.md | 입학연수 핵심 개념 누적 |
| pharma-ai-insights.md | 제약 현장 + AI 연결 인사이트 |

## 사용 규칙
- 파일 덮어쓰기 금지 → 내용 추가(append)만 허용

- pharma-ai-insights.md는 AI-tutor 세션 후 바로 기록
